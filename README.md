# EAS587-data-intensive-project The Attention Span of the World
Semester project for EAS 587: Data Intensive Computing

## Project Overview 

This project studies how global media attention rises, peaks and declines following major real-world events using GDELT 2.0.

We initally focus on:
- Technology announcements
- Scientific discoveries
- Corporate events

## Primary dattasets 

GDELT 2.0

Core data: 
- Events
- Mentions

Potential enrichment:
- Global Knowledge Graph (GKG)
